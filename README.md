# Три режима работы с неопределённостью

Конспект лекции-кейнота. Каждый файл в `_slides/` — это один слайд.

**Сайт:** https://stepanovis.github.io/lectures-three-modes

## Как добавить слайд

Создай файл `_slides/NN-название.md`:

```yaml
---
layout: slide
title: "Название слайда"
subtitle: "Подзаголовок (необязательно)"
slide_number: NN
---

Текст заметок...
```

Слайды сортируются по полю `slide_number`.
